**Estudiante:** Jerónimo Bermúdez Hernández

**Fecha de entrega:** 13 de junio de 2026

## Descripción

Este ejercicio aplica técnicas básicas de procesamiento de imágenes en Python y OpenCV. Se realiza suavizado con filtro gaussiano, detección de bordes con Canny y detección de objetos con YOLOv8.

## Objetivos

- Cargar una imagen y convertirla a distintos espacios de representación.
- Aplicar un filtro de suavizado para reducir ruido.
- Detectar bordes relevantes en la imagen.
- Ejecutar detección de objetos con un modelo preentrenado de YOLOv8.
