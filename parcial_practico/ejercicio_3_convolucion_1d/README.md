## Descripción

Implementación manual de una convolución unidimensional en Python para aplicar un filtro de promedio móvil sobre una señal discreta.

## Objetivos

- Definir una señal de entrada y un kernel de convolución.
- Implementar la convolución de forma manual, sin usar funciones listas de biblioteca.
- Visualizar la señal original, el kernel y el resultado final.
